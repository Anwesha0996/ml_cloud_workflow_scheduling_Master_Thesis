# ML-based Cloud Workflow Scheduling

This repository contains the ongoing work for my Master's thesis.

Title:
ML-based Network and Resource-Aware Scheduling of Dockerized Applications on Kubernetes in Distributed Cloud Systems

Status:
Work in Progress (Master’s Thesis)

Expected completion: June 2026

## Project Overview

The project investigates how machine learning can improve scheduling decisions in distributed cloud systems.

Key components:

- Synthetic cluster infrastructure generator
- Workflow simulation
- ML-based scheduling model
- Performance evaluation
